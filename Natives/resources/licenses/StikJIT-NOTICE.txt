The upstream framework is redistributed unmodified when built-in JIT is enabled.

The framework includes the idevice library and FFI.
Source: https://github.com/jkcoxson/idevice
License: MIT (idevice-MIT.txt).

Amethyst's UniversalJIT26.js and UniversalJIT26Extension.js remain its existing
debugger protocol. The framework is hosted in a separate AmethystJITHelper
extension using the classic NSExtension process model also used by LiveContainer
and iDeck/Madeira. iDeck's integration was consulted as an architecture reference:
https://github.com/kuscholar/iDeck/tree/main/app/MadeiraJITHelper
